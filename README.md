# Кинотеатр — страница бронирования билетов

Учебный frontend-проект страницы кинотеатра. В проекте используются HTML, CSS и JavaScript без сборщика.

## Запуск
Откройте `index.html` в браузере. Для удобства разработки можно использовать расширение Live Server в VS Code.

## Этапы разработки и ветки
- `stage-1` — базовая HTML-структура и изображения проекта.
- `stage-2` — стили страницы и адаптивная вёрстка (`css/`).
- `stage-3` — интерактивность: выбор мест, подсчёт стоимости и мобильное меню (`js/`).
- `stage-4` — документация проекта.
- `stage-5` — финальная подготовка репозитория.
- `main` — итоговая версия проекта.

Ветки отражают последовательные контрольные точки на основе файлов, доступных в предоставленном архиве. Это не восстановленная исходная история разработки.

## Технологии
- HTML5
- CSS3
- JavaScript
